Uma fonte **gratuita** para o [Hydra Launcher](https://github.com/hydralauncher/hydra) **também podendo ser utilizada sem o Hydra** com links de download de **mods de Doki Doki Literature Club! traduzidos para português do Brasil**, para facilitar a vida de quem tem dificuldade em achar e instalar.

## Como adicionar a fonte no Hydra

1. Abra o Hydra e vá em **Ajustes (configurações) › Fontes de download › Adicionar fonte**.

2. Cole este endereço e confirme:

```
Ainda estou trabalhando nisso 👀
```

3. Clique em **Sincronizar**.

4. Procure **Doki Doki Literature Club!** No catálogo e abra **Ver opções de download**. Os mods aparecem na lista, com um breve tutorial de como instalá-los.

## Como instalar um mod

###  - Dentro do Hydra 

1. **Instale o DDLC original** (gratuito, em [https://ddlc.moe](https://ddlc.moe/)) e preferencialmente jogue antes. Esta fonte **não distribui o jogo base**.

2. No Hydra, escolha o mod na lista e baixe. O Hydra extrai o arquivo sozinho.

3. Copie o conteúdo do mod (normalmente a pasta `game`) para dentro da pasta do seu DDLC, **mesclando e substituindo** os arquivos quando o sistema perguntar.

4. Abra o jogo. Se o mod tiver instruções próprias, elas valem mais do que este passo a passo.

> Dica: faça uma cópia da pasta do DDLC antes, para ter uma versão limpa do jogo e instalar um mod diferente depois.

### - Fora do Hydra

1.  **Instale o DDLC original** (gratuito, em [https://ddlc.moe](https://ddlc.moe/)) e preferencialmente jogue antes.

2. O arquivo geralmente vem em formato compactado (.zip ou .tar.gz para Linux) ou como um instalador direto.

3. Clique com o botão direito sobre o arquivo compactado e selecione "Extrair aqui" (ou use um gerenciador de compactação como WinRAR, 7-Zip ou a ferramenta nativa do seu sistema)

4. Uma nova pasta com o nome do jogo será criada contendo todos os arquivos necessários (incluindo o executável principal DDLC.exe ou equivalente).

5. ​Na pasta do jogo copie ou recorte os arquivos do mod desejado

6. **Copie para a Pasta `game`:**
   Navegue até a pasta raiz onde você extraiu o **DDLC original**.
    Abra a pasta chamada **`game`**.
    Mova/cole todos os arquivos do mod **diretamente dentro da pasta `game`**.
   *Se o sistema perguntar se deseja substituir arquivos existentes,  `confirme ` em **"Sim / Substituir"**

O próprio jogo DDLC e vários mods tratam de temas pesados (saúde mental, tristeza, terror). Confira a categoria de cada mod na tabela antes de jogar, mas já estejam cientes que como o próprio jogo tem temas pesados, alguns dos mods se trataram de coisas parecida.
